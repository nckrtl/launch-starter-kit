# Orbit project maintenance

Use these skills for the registered Commander project `orbit`.

Read Orbit's current project record in the shared-knowledge registry. Use its `locations` to select the checkout, `routing.linear` for issue ownership, and `orchestration.board` for its board. An assigned worktree supplies the checkout for that task.

| Task | Skill |
| --- | --- |
| Draft or update a Linear issue from defined work | [creating-issues](skills/creating-issues/SKILL.md) |
| Resolve gaps in an existing issue or the backlog | [resolve-pipeline-issues](skills/resolve-pipeline-issues/SKILL.md) |
| Diagnose failed main checks or cache maintenance | [maintaining-monorepo](skills/maintaining-monorepo/SKILL.md) |

For feature work, read `AGENTS.md` in the selected Orbit checkout. Its `.agents/skills/` directory owns shaping, architecture, documentation, implementation, and PR quality. Use those skills directly and return their results to the maintenance task.

Keep plans, task decomposition, progress, and working evidence in the project's shared knowledge. Use the current Commander assignment for the task's expected result and any publication authority.
