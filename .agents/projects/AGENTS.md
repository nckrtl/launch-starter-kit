# Project skills

Store maintainer skills under `.agents/projects/<project-id>/skills/`. The directory name is the project's ID in Commander's shared-knowledge registry.

When the task concerns a managed project, identify that project from its current record and read `.agents/projects/<project-id>/AGENTS.md`. Select the skill for the requested task. Read the project's checkout instructions for implementation and review work.
